CLEAR SPACE RULE
Minimum clear space = 1× logo height on all sides. Never place on low-contrast backgrounds or distort proportions.
✅ Brand Usage — Do's
✓ DO
Use the logo on backgrounds with a contrast ratio ≥ 4.5:1
✓ DO
Always use Space Grotesk for headings and UI copy
✓ DO
Use the brand gradient (purple → cherry) for primary CTAs
✓ DO
Maintain minimum padding around the logo mark
✓ DO

✕ DON'T

✕ DON'T
