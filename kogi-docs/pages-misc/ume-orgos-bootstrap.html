Step 4 of 7 · Actors & ODD Contracts

Register OrgExecs & OrgCPUs

Every actor in your OrgOS — human, AI agent, hybrid, or device — must have an OrgDeviceDriver (ODD) contract. All actions are validated in <5ms p99 and recorded in the immutable audit chain.

Universal ODD enforcement: AI agents are subject to identical ODD validation as human OrgExecs. No actor type is exempt. Self-modification of ODD constraints by AI requires explicit human OrgExec approval.

Step 6 of 7 · Provisioning

Booting your OrgOS

The UME OrgOS Factory is executing the 9-step provisioning sequence. Your OrgDNA is being committed to immutable storage. This takes under 90 seconds.

1
Validating OrgDNA package
OrgDNALoader::validate() — all deps, config integrity, size check
2
Allocating infrastructure
OrgOSFactory::allocate_resources() — db schema namespace · S3 prefix · executor threads
3
Running database migrations
StorageManager::migrate_all() — schema init for all selected OrgApps
4
Instantiating OrgKernel
OrgKernel::new() — Rust boot · Tokio runtime · event bus · kernel facade
5
Registering ODD templates
ODDBus::load_from_orgdna() — Human · AI Agent · OrgCPU · Hybrid contracts
6
Booting OrgApps
OrgAppRegistry::boot_all() — dependency order · event subscriptions registered
7
Initialising SDO engine
SDOEngine::initialize() — topology graph · state snapshots · health baseline
8
Loading jurisdiction packs
Chombo::load_packs() — policy rules compiled · filing calendar generated
9
Publishing OrgOS endpoints
kernel.event_bus.publish(OrgOSProvisionedEvent) — HTTP API live
