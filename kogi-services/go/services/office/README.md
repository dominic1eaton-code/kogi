# office-service

Kogi Office module service.

## Endpoints
- `GET /health`
- `GET /api/v1/office`
- `GET /api/v1/office/dashboard`
- `GET /api/v1/office/portfolio`
- `GET /api/v1/office/timeline`
- `GET /api/v1/office/workspace`
- `GET /api/v1/office/assistant`

## Run
```powershell
go run ./kogi-services/go/services/office
```
